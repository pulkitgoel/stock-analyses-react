This is the latin subset (U+0000-00FF plus the usual punctuation and symbol
ranges) of the Inter variable font, as served by Google Fonts (Inter v20). It is
a variable font covering the full weight axis, so one file serves weights 400,
600 and 700 — Google Fonts returns the same URL for all three.

It is committed rather than fetched at build time so the site serves its own
font from its own origin. See AGENTS.md 7.11.
